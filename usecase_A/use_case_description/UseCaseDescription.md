# UC01 회원가입

```
Use Case Name: 회원가입
Actor: 비회원

Precondition:
- 비회원이 회원가입 화면에 접근할 수 있다.

Main Flow:
1. 비회원은 회원가입 화면으로 이동한다.
2. 시스템은 회원가입 화면을 표시한다.
3. 비회원은 ID, 비밀번호, 이름, 전화번호, 이메일을 입력한다.
4. 비회원은 회원가입 버튼을 선택한다.
5. 시스템은 입력 정보를 확인한다.
6. 시스템은 회원가입 완료 메시지를 표시한다.

Alternative Flow:
A1. 필수 입력 항목이 누락된 경우
1. 시스템은 입력 오류 메시지를 표시한다.

A2. 중복된 ID를 입력한 경우
1. 시스템은 중복 ID 오류 메시지를 표시한다.

Postcondition:
- 새로운 회원 정보가 등록된다.
```

# UC02 로그인

```
Use Case Name: 로그인
Actor: 회원, 관리자

Precondition:
- 회원 또는 관리자가 로그인 화면에 접근할 수 있다.

Main Flow:
1. 회원 또는 관리자는 로그인 화면으로 이동한다.
2. 시스템은 로그인 화면을 표시한다.
3. 회원 또는 관리자는 ID와 비밀번호를 입력한다.
4. 회원 또는 관리자는 로그인 버튼을 선택한다.
5. 시스템은 로그인 결과 화면을 표시한다.

Alternative Flow:
A1. 로그인 정보가 올바르지 않은 경우
1. 시스템은 로그인 실패 메시지를 표시한다.

Postcondition:
- 회원 또는 관리자가 로그인된다.
```

# UC03 회원 탈퇴

```
Use Case Name: 회원 탈퇴
Actor: 회원

Precondition:
- 회원이 로그인되어 있다.

Main Flow:
1. 회원은 회원 탈퇴 메뉴를 선택한다.
2. 시스템은 회원 탈퇴 확인 팝업을 표시한다.
3. 회원은 확인 버튼을 선택한다.
4. 시스템은 회원 탈퇴 완료 메시지를 표시한다.

Alternative Flow:
A1. 회원이 탈퇴를 취소하는 경우
1. 회원은 취소 버튼을 선택한다.
2. 시스템은 팝업을 닫는다.

Postcondition:
- 회원 정보가 삭제된다.
```

# UC11 통계 조회

```
Use Case Name: 통계 조회
Actor: 관리자

Precondition:
- 관리자가 로그인되어 있다.

Main Flow:
1. 관리자는 통계 조회 화면으로 이동한다.
2. 시스템은 통계 조회 화면을 표시한다.
3. 관리자는 검색 단위를 선택한다.
4. 관리자는 조회 버튼을 선택한다.
5. 시스템은 선택한 기간의 전체 설문 수를 표시한다.
6. 시스템은 선택한 기간의 종료된 설문 수를 표시한다.
7. 시스템은 선택한 기간의 총 응답 수를 표시한다.

Postcondition:
- 관리자는 설문 응답 통계 정보를 확인한다.
```
