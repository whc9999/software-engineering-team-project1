설문 검색

| Actor Action | System Response |
| :---- | :---- |
|   | 1\. 설문 검색 메뉴를 표시한다. |
| 2\. 회원이 설문 검색 기능을 선택한다. |   |
|   | 3\. 진행 중인 설문 리스트, 진행 예정 설문 리스트, 종료된 설문 리스트 선택 항목과 검색창을 표시한다. |
| 4\. 회원이 설문 리스트 중 하나를 선택하고, 키워드를 입력한 후 검색 버튼을 누른다. |   |
|   | 5\. 조건에 맞는 설문 리스트를 출력한다. |

 

설문 상세정보 조회

| Actor Action | System Response |
| :---- | :---- |
|   | 1\. 검색된 설문 리스트 화면을 출력한다. |
| 2\. 회원이 특정 설문을 클릭한다. |   |
|   | 3\. 해당 설문의 상세 정보(설문 제목, 설문 설명, 설문 문항, 응답 항목, 설문 시작 시각, 설문 마감 시각 등)를 출력한다. |

 

설문 응답

| Actor Action | System Response |
| :---- | :---- |
|   | 1\. 진행 중인 설문의 응답 버튼을 화면에 표시한다. |
| 2\. 회원이 응답 버튼을 선택한다. |   |
|   | 3\. 설문 응답 화면을 출력한다. |
| 4\. 회원이 설문 문항을 작성한 후 응답 완료버튼을 누른다. |   |
|   | 5\. 응답 완료 메시지를 출력한다. |
