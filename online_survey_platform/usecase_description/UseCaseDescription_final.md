회원가입

| Actor Action | System Response |
| :---- | :---- |
|  | 1\. 회원가입 화면을 표시한다. |
| 2\. 비회원이 ID, 비밀번호, 이름, 전화번호, 이메일을 입력한 후 회원가입 버튼을 누른다. |  |
|  | 3\. 회원가입 완료 메세지를 출력한다. |

회원 탈퇴

| Actor Action | System Response |
| :---- | :---- |
|  | 1\. 회원 탈퇴 화면을 표시한다. |
| 2\. 회원이 회원 탈퇴 확인 버튼을 누른다. |  |
|  | 3\. 회원탈퇴 완료 메세지를 출력한다. |

로그인

| Actor Action | System Response |
| :---- | :---- |
|  | 1\. 로그인 화면을 표시한다. |
| 2\. 회원 또는 관리자가 ID와 비밀번호를 입력한 후 로그인 버튼을 누른다. |  |
|  | 3\. 로그인 결과 화면을 표시한다. |

설문 등록

| Actor Action | System Response |
| :---- | :---- |
|  | 1\. 설문 정보 입력 폼을 표시한다. |
| 2\. 관리자가 입력 정보(설문 제목, 설문 설명, 응답 항목, 설문 시작 시각, 설문 마감 시각) 입력 후 등록 버튼을 클릭한다. |  |
|  | 3\. 작성한 설문 등록에 성공했다는 메세지를 출력한다. |

설문 조회

| Actor Action | System Response |
| :---- | :---- |
|  | 1\. 등록된 모든 설문 리스트를 출력한다. |

설문 조회 Extend1. 설문 상세 내용 조회

| Actor Action | System Response |
| :---- | :---- |
| 2.1. 관리자가 설문 리스트 조회 화면에서 특정 설문 항목을 선택한다. |  |
|  | 3.1. 해당 설문의 상세 내용을 팝업 창 형태로 출력한다. |

설문 조회 Extend2. 설문 삭제

| Actor Action | System Response |
| :---- | :---- |
| 2.2. 관리자가 설문 리스트 조회 화면에서 삭제하려는 설문 항목을 선택한 후 삭제 버튼을 누른다. |  |
|  | 3.2. 해당 설문 항목 삭제에 성공했다는 메세지를 출력한다. |

설문 검색

| Actor Action | System Response |
| :---- | :---- |
|   | 1\. 설문 검색 메뉴를 표시한다. |
| 2\. 회원이 설문 검색 기능을 선택한다. |   |
|   | 3\. 진행 중인 설문 리스트, 진행 예정 설문 리스트, 종료된 설문 리스트 선택 항목과 검색창을 표시한다. |
| 4\. 회원이 설문 리스트 중 하나를 선택하고, 키워드를 입력한 후 검색 버튼을 누른다. |   |
|   | 5\. 조건에 맞는 설문 리스트를 출력한다. |

 

설문 상세정보 조회

| Actor Action | System Response |
| :---- | :---- |
|   | 1\. 검색된 설문 리스트 화면을 출력한다. |
| 2\. 회원이 특정 설문을 클릭한다. |   |
|   | 3\. 해당 설문의 상세 정보(설문 제목, 설문 설명, 설문 문항, 응답 항목, 설문 시작 시각, 설문 마감 시각 등)를 출력한다. |

 

설문 응답

| Actor Action | System Response |
| :---- | :---- |
|   | 1\. 진행 중인 설문의 응답 버튼을 화면에 표시한다. |
| 2\. 회원이 응답 버튼을 선택한다. |   |
|   | 3\. 설문 응답 화면을 출력한다. |
| 4\. 회원이 설문 문항을 작성한 후 응답 완료버튼을 누른다. |   |
|   | 5\. 응답 완료 메시지를 출력한다. |

 

통계조회

| Actor Action | System Response |
| :---- | :---- |
|  | 1\. 통계 조회 화면을 표시한다. |
| 2\. 관리자가 조회기간(최근 1주일, 1개월, 1년)을 선택한 후 조회 버튼을 누른다. |  |
|  | 3\. 조건에 맞는 설문 통계 화면을 출력한다. |
